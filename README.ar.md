# JSON Builder

[English](README.md)

JSON Builder هو تطبيق Android يساعد المطورين على إنشاء بيانات JSON وتحريرها ومعاينتها وإدارة عدة مشاريع JSON من خلال واجهة مرئية وتفاعلية.

صُمم التطبيق للمطورين الذين يحتاجون إلى إعداد هياكل JSON، واختبار نماذج البيانات، وإنشاء أجسام طلبات API، وحفظ قوالب JSON قابلة لإعادة الاستخدام دون كتابة كل جزء من مستند JSON يدوياً.

## أصل المشروع

تم إنشاء هذا التطبيق بالكامل باستخدام الذكاء الاصطناعي من Google، وباستخدام **Gemini 4 Hydrogen** من خلال منصة **Google AI Studio**.

تمت كتابة ملفي التوثيق `README.md` و`README.ar.md` بواسطة **Manus**.

> التطبيق نفسه لا يوفر حالياً واجهة مستخدم باللغة العربية. دعم العربية في هذا المستودع خاص بملفات التوثيق فقط.

## المزايا

- إنشاء كائنات JSON وتحريرها بطريقة مرئية.
- إضافة خصائص JSON وتعديلها وحذفها.
- التعامل مع القيم النصية والرقمية والمنطقية وقيم `null`.
- إنشاء الكائنات والمصفوفات المتداخلة.
- معاينة JSON الناتج في الوقت الحقيقي.
- تنسيق JSON ليكون أسهل في القراءة.
- التحقق من بنية JSON الناتج.
- إنشاء وإدارة عدة مشاريع JSON.
- حفظ المشاريع محلياً على الجهاز.
- نسخ JSON الناتج لاستخدامه في أدوات التطوير الأخرى.
- استخدام واجهة Android حديثة مبنية باستخدام Jetpack Compose.

## الاستخدامات المحتملة

### تطوير واجهات API

إنشاء أجسام الطلبات الخاصة بواجهات `POST` و`PUT` و`PATCH` قبل اختبارها باستخدام أدوات مثل Postman أو Insomnia.

### إعداد بيانات تجريبية

إنشاء بيانات JSON تجريبية لاختبار شاشات التطبيقات وتكاملات API وحالات البيانات المختلفة قبل ربط التطبيق بالخادم الفعلي.

### تطوير تطبيقات Android وتطبيقات الهاتف

إنشاء نماذج بيانات قابلة لإعادة الاستخدام واختبارها أثناء تطوير تطبيقات Android أو iOS أو التطبيقات متعددة المنصات.

### تطوير الويب والخوادم

إعداد بيانات JSON، وكائنات الإعدادات، وأمثلة الاستجابات لخدمات الويب وتطبيقات الخادم.

### التعلم والتدريب

استخدام الواجهة المرئية لفهم كائنات JSON والمصفوفات والقيم الأساسية والهياكل المتداخلة.

### إدارة ملفات الإعدادات

إنشاء وتعديل ملفات الإعدادات التي تعتمد على JSON وتستخدمها التطبيقات والخدمات والبرامج النصية وأدوات التطوير.

### حفظ قوالب البيانات

الاحتفاظ بعدة مشاريع JSON للهياكل المتكررة، مثل المستخدمين والمنتجات والطلبات والإعدادات واستجابات API.

## نظرة عامة على بنية التطبيق

### النماذج

تحتوي طبقة النماذج على العناصر التي تمثل مكونات JSON، بما في ذلك الكائنات والمصفوفات والقيم الأساسية.

### محرك JSON

يحوّل محرك JSON بنية البيانات المرئية إلى نص JSON منسق، ويتولى عمليات التحقق والمعالجة المتعلقة بـ JSON.

### طبقة البيانات المحلية

يستخدم التطبيق Room Database لحفظ مشاريع JSON محلياً على الجهاز.

### Repository

تفصل طبقة Repository مصادر البيانات عن بقية أجزاء التطبيق، وتوفر واجهة واضحة للوصول إلى المشاريع المحفوظة.

### ViewModel

يدير ViewModel حالة الشاشة وعمليات التعديل وإدارة المشاريع والتواصل مع طبقة البيانات.

### واجهة المستخدم

تم بناء واجهة المستخدم باستخدام Jetpack Compose، وقُسمت إلى مكونات قابلة لإعادة الاستخدام لتسهيل الصيانة والتطوير مستقبلاً.

## تشغيل المشروع

1. افتح Android Studio.
2. اختر **Open**.
3. حدد المجلد الرئيسي للمشروع.
4. انتظر حتى تنتهي مزامنة Gradle.
5. شغّل التطبيق على محاكي Android أو جهاز Android متصل.

لبناء نسخة Debug APK من المجلد الرئيسي للمشروع، نفّذ الأمر التالي:

```bash
./gradlew assembleDebug
```

سيتم إنشاء ملف APK في المسار التالي:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## الاختبارات

لتشغيل اختبارات Android المتصلة:
